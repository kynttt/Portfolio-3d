# Selected Systems Visual Assets

Place the final project visuals in this directory using these exact filenames:

1. `genius.webp`
2. `field-systems.webp`
3. `poseidon.webp`
4. `ai-product-lab.webp`

The gallery automatically displays a final image when its file exists. Until then, each card uses its built-in technical case-file placeholder. Replacing a placeholder only requires adding the corresponding file here.

## Image Direction

- Use monochrome or near-monochrome imagery.
- Keep the dark technical-interface character of the portfolio.
- Avoid colorful UI screenshots, stock photography, and unrelated imagery.
- Abstract or anonymize operational data.
- Keep the mechanical-futurist visual identity consistent across all four cards.

## Recommended Export

- Export at `1600 x 1000` pixels or larger.
- Use the same `8:5` aspect ratio for every image.
- Use optimized WEBP files.
- Keep important details near the center.
- Leave enough dark negative space for overlays and interface labels.
- A subtle dark overlay may be applied for readability.

## Project-Specific Content

- `genius.webp`: utility map, node markers, electric distribution paths, dashboard panels, and geospatial layers.
- `field-systems.webp`: mobile interfaces, map tiles, pole markers, offline status, photo capture states, and sync indicators.
- `poseidon.webp`: route map, origin/destination points, quote calculation panels, shipment metadata, and logistics dashboard fragments.
- `ai-product-lab.webp`: knowledge graph, document chunks, retrieval paths, node network, ranking metadata, and AI workflow diagrams.
