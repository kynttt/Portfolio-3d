# Origin Outro Ripple Trail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the skeleton beneath the original portrait and let cursor ripples temporarily cut through the portrait, leaving a soft 650ms reveal trail.

**Architecture:** Render an aligned skeleton image as the bottom layer and the original portrait as a top cover. Maintain a short list of pointer trail samples in the reveal component; convert those samples into browser-safe radial mask layers that punch fading holes through the portrait cover. Keep the existing CursorRipples shader as a narrow skeleton wavefront above both images so the ripple remains visibly fluid without exposing the entire skeleton.

**Tech Stack:** Next.js 15, React 19, TypeScript, CSS masks, shaders/react CursorRipples, Playwright Core verification.

## Global Constraints

- Change only the Origin light-outro reveal and its focused verification.
- Preserve the existing portrait and skeleton alignment.
- Reveal trail lifetime is 650ms.
- The portrait is fully restored after the trail fades.
- No circular border and no full-skeleton hover state.
